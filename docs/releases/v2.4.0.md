## 🌟 Executive Summary

**Release v2.4.0** transforms the Bus Reservation System into an installable cross-platform Progressive Web App (PWA) and publishes a production native Android package (Trusted Web Activity). 

This release achieves 100% compliance with Microsoft PWABuilder and Google Play Store packaging standards, adds Web Push notifications, Background Sync, Windows 11 desktop widgets, custom protocol schemes, and digital asset domain verification.

---

## 🚀 Key Highlights

### 1. 📱 Native Android Package (Trusted Web Activity)
- **Direct Sideload APK (`BusBooking.apk`, ~999 KB):** Single-click installation on Android 5.0+ devices.
- **Google Play Store AAB Bundle (`BusBooking.aab`, ~1.08 MB):** Optimized production App Bundle signed with production release keystore (`signing.keystore`).
- **Cryptographic Digital Asset Links (`.well-known/assetlinks.json`):** Hosted live at `https://bus-resrvation.onrender.com/.well-known/assetlinks.json` to verify package ownership and unlock a true full-screen experience with zero browser address bars.

### 2. ⚡ Progressive Web App (PWA) Architecture
- **Web App Manifest (`manifest.json`):** Complete standalone configuration with 30/30 PWABuilder checks passing (Required, Recommended, and Optional).
- **Service Worker (`sw.js`):** Production caching engine (`sbtbs-bus-cache-v1`) with non-GET mutation guards and automatic offline fallback routing (`offline.html`).
- **Path-Aware Layout Head (`_pwa-head.php`):** Dynamically resolves root (`./`) vs admin (`../`) asset scopes, incorporates print style suppression, and injects floating install banners.

### 3. 🔔 Web Push & Background Sync
- **Web Push Notifications:** Service worker handles remote push messages with interactive action buttons (*View Ticket*, *Dismiss*), vibration patterns, and focus-navigation integration.
- **Background Sync API (`sync`):** Queues customer inquiries and submits them automatically upon network reconnection.
- **Periodic Background Sync (`periodicsync`):** Automatically pre-caches daily bus route schedules every 12 hours.

### 4. 🪟 Desktop & Operating System Integrations
- **Windows 11 Widgets Board:** Adaptive Cards integration with live preview templates and data feeds (`widgets/bus-widget.json`, `widgets/bus-widget-data.json`).
- **Microsoft Edge Side Panel:** Support for 400px preferred width sidebar layout.
- **Window Controls Overlay:** Customized titlebar integration with native window controls and draggable header regions.
- **Tabbed Display Mode:** Multi-document tabs within the standalone desktop app window.
- **Protocol Handlers:** Registered `web+bus` and `web+ticket` URI schemes with instant PNR resolution in `pnr.php`.
- **Web Share Target API:** Inbound share handler receiving PNR vouchers shared via messaging apps.
- **File Handlers:** Native desktop file associations for `.ticket`, `.json`, and `.csv`.

### 5. 🎨 UI/UX & Administrative Elevation
- **Performance Overview Analytics:** Live KPI stat cards, interactive charts, and 7/30/90-day time-window filtering.
- **Departure Schedule Carousel:** Auto-cycling schedule showcase on desktop and swipe-snap carousel on mobile.
- **Mobile Responsive Tables:** Stacked card view for admin tables below 768px with swipeable sidebar navigation.

## 📥 Getting Started with v2.4.0

### Run via Docker
```bash
docker pull ghcr.io/jashan-randhawa/bus-reservation:v2.4.0
docker run -d -p 8080:80 \
  -e DB_HOST=your-db-host \
  -e DB_USER=your-db-user \
  -e DB_PASSWORD=your-db-pass \
  -e DB_NAME=sbtbsphp \
  ghcr.io/jashan-randhawa/bus-reservation:v2.4.0
```

### Install Android App via ADB
```bash
adb install -r packages/app/BusBooking.apk
```

### Install npm Packages
```bash
npm install @jashan-randhawa/busres-ui@1.0.1
npm install @jashan-randhawa/bus-seat-picker@1.0.0
```
