Mobile Footer Architecture & Viewport Audit

Project: Bus-Reservation • Platform: PHP 8.3/8.4, Vanilla CSS3, MySQL, PWA • Author: Engineering & UI Architecture Team

1. Executive Summary & Mobile Audit

An audit of the responsive viewport ergonomics (range 320px to 768px) on mobile browsers and installed Progressive Web App (PWA) environments reveals four primary usability barriers when standard desktop multi-column footers are served without adaptive structural partials:

Vulnerability / Issue Mobile Viewport Phenomenon (≤ 768px) Architectural Remedy Implemented
Horizontal Overflow Fixed grid fractions and unconstrained padding cause horizontal page jitter and viewport expansion beyond 100vw. Enforced strict box-sizing: border-box, max-width: 100%, and overflow-x: hidden on the root footer wrapper.
Endless Vertical Scroll 4 desktop columns stack sequentially, creating an unreadable 650px+ text column before users reach copyrights or disclaimers. Integrated native semantic HTML5 <details> accordions on mobile that automatically unfold into a 4-column CSS Grid on desktop.
Cramped Touch Targets Desktop anchor tags with 20px–24px vertical footprints trigger mis-taps and accidental navigation on capacitive touchscreens. Enforced WCAG 2.1 Level AAA compliant touch targets with min-height: 44px and isolated tap zones.
PWA Bottom-Nav Clashing When running under display-mode: standalone, native fixed bottom action bars occlude the sub-footer copyright and policies. Applied dynamic safe-area offset padding: padding-bottom: calc(76px + env(safe-area-inset-bottom, 0px)).

2. Modular Partials Architecture

Rather than embedding monolithic footer markup in individual view files (homepage.php, user/index.php, admin/dashboard.php), the system separates public desktop web utility from standalone mobile app navigation using clean PHP partials:

  • includes/footer.php: Full semantic web footer with mobile accordion columns and PWA install trigger.
  • includes/bottom-nav.php: Glassmorphic fixed bottom navigation bar (Home, Search, My Tickets, Profile) active on mobile viewports and PWA standalone mode.
  • admin/includes/footer.php: Minimalist administrative utility bar (system operational telemetry, TLS 1.3 indicator, engine status).
  • assets/css/footer.css: Scoped design tokens, media queries, specular highlights, and print styles.

4. Mobile-First CSS Ergonomics (`assets/css/footer.css`)

/* Mobile Accordion & Touch Ergonomics */ @media (max-width: 768px) { .website-only-footer { padding-bottom: calc(76px + env(safe-area-inset-bottom, 0px)); overflow-x: hidden; } .footer-grid { grid-template-columns: 1fr; gap: 0; } .footer-col-accordion { border-bottom: 1px solid var(--footer-border); } .footer-col-accordion summary.footer-title { cursor: pointer; min-height: 44px; display: flex; align-items: center; justify-content: space-between; padding: 0.85rem 0; margin-bottom: 0; } .footer-col-accordion summary.footer-title::after { content: '+'; font-size: 1.25rem; color: var(--footer-accent); } .footer-col-accordion[open] summary.footer-title::after { content: '\2212'; /* Minus sign */ } .footer-link { min-height: 44px; /* Ergonomic touch target */ display: inline-flex; align-items: center; width: 100%; } }
